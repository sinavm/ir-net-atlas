# Security Policy

Please do not report suspected vulnerabilities in public issues, discussions,
or pull requests. Use GitHub's **Report a vulnerability** feature in this
repository's Security tab for private disclosure. Include the affected
component and version or commit, impact, safe reproduction steps, and possible
mitigation.

If private reporting is unavailable, contact the maintainer through the
contact method on the SiNAVM GitHub profile and request a private channel.
Allow reasonable time for investigation and coordinate public disclosure.
Do not access, alter, or exfiltrate data that is not yours, or disrupt
services during testing.

This policy covers only assets the maintainer owns or is authorized to
maintain. It does not authorize testing third-party services or upstream
projects, grant legal immunity, or override applicable law. Reports will be
reviewed as reasonably practicable; no fixed response or remediation deadline
is promised.
